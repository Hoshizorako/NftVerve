# NftVerve

Employs high-performance, real-time processing for auto-scaling NFT data management, leveraging an orchestrator controller architecture.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/NftVerve.git`
2. `cd NftVerve`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure NftVerve, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
